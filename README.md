# Student Management System

## 🎯Project Overview
This is a simple Student Management System developed using Python.
It stores student records in a JSON file.

## 📩Features
- Add Student
- View Students
- Search Student by ID
- Update Student Details
- Delete Student
- Prevent Duplicate Student IDs
- Save Data Using JSON

## 🛠️Technologies Used
- Python
- JSON

## 🔀How to Run
1. Install Python.
2. Download the project file.
3. Open the file in Python IDLE.
4. Press F5 to run the program.
